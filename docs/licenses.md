# Licenses and distribution checks

[Home](../README.md) · [Component map](serviceMap.md) · [Change ledger](change-ledger.md)

The owner's Git authorship was checked against the actual GitHub identity before
licensing original code/documents as MIT. This does not relicense dependencies,
fonts, bundled upstream source or private knowledge. The table records checks,
not a claim of complete legal compatibility. Each owner preserves its own
THIRD_PARTY_NOTICES and the upstream texts required by its actual artifacts.
